# دفتر — DAFTAR | المحاسب الذكي (تطبيق Android الأصلي)

تطبيق محاسبي وإداري ونقاط بيع متكامل يعمل **محلياً بنسبة 100% دون اتصال بالإنترنت**، مبني بلغة **Kotlin** وواجهة **Jetpack Compose + Material 3** وفق المرجع التصميمي الرسمي لمشروع **DAFTAR**.

## المزايا الهندسية والمحاسبية
- **عزل الأنشطة بالكامل**: قاعدة **SQLCipher (AES-256)** مستقلة ومفتاح تشفير مستقل عبر **Android Keystore** لكل نشاط.
- **السودان كإعداد افتراضي (`SD` / `SDG`)** مع تعدد العملات وحفظ سعر الصرف التاريخي وقت كل عملية دون تغيير العمليات السابقة.
- **المحاسبة المزدوجة الصارمة (`BigDecimal`)**: أرصدة مشتقة من سطور القيود المرحلة، منع ترحيل القيود غير المتوازنة، ومنع حذف القيود المرحلة مع التصحيح عبر القيود العكسية الموثقة.
- **37 وحدة و41 شاشة** مع تفعيل قطاعي متكيّف حسب نوع النشاط (التجزئة، المطاعم، الصيدليات FEFO، الورش، المصانع BOM، المؤسسات الخدمية).
- **اختبار الاستعادة التجريبي (Dry-Run)** قبل الموافقة الصريحة، ونسخ احتياطي مشفر **AES-256-GCM + SHA-256** عبر Android SAF.

## أوامر البناء والاختبار محلياً
```bash
cd android
chmod +x gradlew
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
```
ملف APK الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`
